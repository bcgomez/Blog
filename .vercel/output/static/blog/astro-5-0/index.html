Novedades Astro 5.0

3/12/2024 Noticias

Astro 5.0 trae mejoras significativas en rendimiento y usabilidad. En este artículo, exploraremos las novedades más destacadas.

Mejoras de rendimiento

Astro 5.0 incluye optimizaciones que reducen el tiempo de carga y mejoran la experiencia del usuario.

  • Compilación más rápida
  • Mejor manejo de imágenes
  • Optimización de CSS y JS

Nuevas características

Algunas de las nuevas características incluyen:

  • Soporte para nuevos componentes
  • Integración con herramientas populares
  • Mejoras en la documentación
